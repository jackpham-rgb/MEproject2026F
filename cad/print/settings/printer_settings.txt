CONCEPT A: 3D PRINTER SETTINGS (PETG, 0.4 mm nozzle)
=====================================================
PRINTER: Creality CR-6 SE (235 x 235 x 250 mm bed, Bowden extruder, nozzle-probe auto-levelling,
carborundum glass bed). The plates are laid out for 220 x 220, so they fit with room to spare.

CR-6 SE SPECIFICS
  Slicer profile            Cura: Add printer > Creality > "Creality CR-6 SE" (its start code uses the
                            saved levelling mesh). PrusaSlicer: Creality > CR-6 SE, then import the .ini
  Nozzle temperature        235 C, first layer 238 C. Keep it <= 240 C: the stock hotend has a PTFE
                            tube down to the nozzle and PTFE breaks down above ~240 C
  Retraction (Bowden)       5 mm at 40 mm/s. Stringing: try 6 mm; never above 7 mm
  Bed                       carborundum glass at 80 C. PETG grips it hard: thin glue stick as a
                            release layer so the parts don't pull chips out of the glass. Remove parts
                            after the bed has cooled to room temperature
  Levelling                 touch screen > Level, with a CLEAN nozzle (no plastic on the tip: the
                            nozzle itself is the probe). Then adjust Z-offset on the first layer
  Card                      short file names, no spaces (P0COUPON.gcode ...): the screen cuts long names

Files: cad/print/plates/plate0..3 (.3mf = separate parts, keeps per-part settings; .stl = one piece)
       Parts are already turned to their best side. Don't rotate them, except 90 deg flat on the bed.
Slicer: PrusaSlicer -> File > Import > Import Config... -> concept_a_PETG_prusaslicer.ini
        Cura / Bambu / Orca: type the values below in by hand (names in brackets).

PRINT ORDER (times = PrusaSlicer 2.7 estimates with these settings; each plate test-sliced)
  0. plate0_coupon        ~1.0 h   CHECK THE FITS FIRST (build guide section 2). Fix TOL if needed.
  1. plate1_base         ~17 h     overnight: base, turret plate, top cap, lift link
  2. plate2_tray_spine   ~12 h     tray, spine, right finger
  3. plate3_arm_claw      ~8 h     carriage arm, gripper frame, left finger
  Total ~38 h, ~330 g PETG. The fingers are on different plates on purpose: PrusaSlicer 2.7 crashes
  ("G-code path conflict") when the supported left finger shares a plate with the right finger, the
  tray or the base.

PER-PART SETTINGS ARE ALREADY IN THE .3MF FILES (PrusaSlicer)
  Open a plate: supports are on only for the base, turret plate, carriage arm and fingers; the
  fingers are at 100 % infill; the lift link has a 5 mm brim. Right-click a part to see its settings.
  Leave global supports OFF. Cura does not read these: in Cura add them per part by hand
  (Per Model Settings).

MATERIAL: PETG 1.75 mm
  Nozzle temperature        235 C (first layer 238 C, max 240) [printing temperature]
  Bed temperature           80 C (first layer 80 C)          [build plate temperature]
  Cooling fan               30 % (max 50 % on small layers), off for the first 3 layers
  Retraction                bowden (Ender-3): 5 mm at 40 mm/s; direct drive: 1 mm at 35 mm/s
  Bed surface               glue stick on smooth PEI or glass (PETG can weld to bare PEI)
  Dry the filament          if it pops / strings a lot: 65 C for 4 h

QUALITY
  Layer height              0.20 mm (first layer 0.24 mm)
  Line width                0.42 mm
  Walls / perimeters        3 (= 1.2 mm)                     [wall line count]
  Top / bottom layers       4 / 4
  Infill                    30 % gyroid                      [infill density / pattern]
  Elephant-foot comp.       0.15 mm                          [initial layer horizontal expansion = -0.15]
  Seam                      aligned / rear

SPEED
  Outer walls 35 mm/s, inner walls 50 mm/s, infill 70 mm/s, first layer 20 mm/s, travel 150 mm/s

SUPPORTS (only on the parts listed, from the build plate only, never "everywhere")
  Type                      normal / grid (tree is fine too)
  Overhang threshold        50 deg
  Z distance                0.2 mm (one layer: PETG sticks to supports, more gap = easier removal)
  XY distance               0.8 mm
  Parts that need them      CA-101 base, CA-201 turret plate, CA-301 carriage arm, CA-402 / CA-403 fingers

PER-PART OVERRIDES (already set in the .3mf for PrusaSlicer)
  CA-402 / CA-403 fingers   supports + 100 % infill (the 16 gear teeth must be solid)
  CA-101, CA-201, CA-301    supports (from the build plate only)
  CA-302 lift link          5 mm brim (it's 16 mm long, it would come loose)

AFTER PRINTING
  Remove supports with pliers; file the pad and gear faces smooth.
  Holes: run the screw in once by hand to cut threads; ream the LM6UU seats with a 12 mm drill bit
  turned by hand if they are tight. Don't use a power drill on PETG (it melts).

CONCEPT A ELECTRONICS (EE/ee_calcs.py)

1. SERVO SIGNAL (PWM) BASICS
   Servo library on a Uno: Timer1, prescaler 8 -> 0.5 us resolution; one 20 ms frame (50 Hz) for all servos.
   In each frame the pulses go out back to back in attach order: D9 turntable, D10 lift, D6 wrist, D5 gripper.
   width_us = map(angle, 0, 180, min_us, max_us); default 544-2400 us, wrist attached with 500-2500 us.
   (The library subtracts a 2 us trim; ISR latency adds ~1-2 us. Both are inside the servos' deadband.)
   Duty cycle range: 2.7% (0 deg) to 12.0% (180 deg); wrist 2.5% to 12.5%.
   Longest frame use: 4 pulses <= 2400 + 2400 + 2500 + 2400 = 9.7 ms, so all 4 fit in the 20 ms frame.

   Gripper hold: 0.8 N per arm x 44 mm lever x 2 arms = 0.72 kg*cm = 45% of the SG90 stall torque -> ~0.29 A while it holds the can.

   Worst cases outside the normal run: one MG996R stall 2.5 A; all 4 servos jumping at power-up 4.6 A (> 4 A:
   power up with the robot at home; the code writes the home pose before attach so nothing jumps).

4. OTHER CIRCUIT VALUES
   Status LED: (5.0 - 2.0 V) / 220 ohm = 13.6 mA  (Uno pin limit 20 mA recommended, 40 mA absolute)
   START button: INPUT_PULLUP 20-50 kOhm -> 0.1-0.25 mA when pressed; debounced 40 ms in code
   Servo signal inputs draw < 1 mA each from D9/D10/D6/D5
   Supply path: adapter 0.06 + cord 0.1 + jack 0.01 + rail 0.05 ohm (EST)
   Hand calc, rail drop at the run peak: 0.65 A x 0.22 ohm = 0.14 V
   Hand calc, rail drop in an MG996R stall: 3.15 A x 0.22 ohm = 0.69 V
   1000 uF capacitor: a 1 A step for 100 us (adapter response, EST) droops it 1 A x 100 us / 1000 uF = 0.10 V

5. NGSPICE RESULTS (same netlist as EE/ltspice/concept_a_run.cir / _stall.cir)
   normal run : min rail 4.86 V, min Uno 5V 4.86 V, min at MG996R 4.85 V, min at gripper 4.82 V
   MG996R stall: min rail 4.31 V, min Uno 5V 4.31 V, min at MG996R 4.10 V, min at gripper 4.27 V
   Normal run: Uno stays above 4.5 V -> PASS.
   Stall: Uno dips to 4.31 V. Below its 4.5 V / 16 MHz spec but far above the 2.7 V brown-out,
   so it keeps running (no reset). Shorter / thicker cord or the MG996R wired straight to the jack lowers the dip.
